# Ventures — Index

Working documents for specific business ideas Pete is exploring — unlike
`architecture/`, `design/`, and `requirements/`, these are not durable,
project-agnostic methodology. They're project state: a concept and a plan
for one particular venture, expected to change or be abandoned as it's
tested against reality.

- [Pedigree Mesh](pedigree-mesh/concept.md) — agent-governed data mesh:
  domain curator agents own provenance, an independent mesh audits and
  computes pedigree, consumer agents negotiate access under a mandate.
  See also its [business plan](pedigree-mesh/business-plan.md).
- [Tactics game](tactics-game/notes.md) — Godot turn-based tactics side
  project: pure sim / Lua scenarios / AI / replay-only view, rules Pete set,
  status and next ideas.
